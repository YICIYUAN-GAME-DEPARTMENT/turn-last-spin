# 5～8 人前期博弈：问题假设、实验与变更边界

> 状态：探索提案。**不属于已确认规则，不能直接施工。**  
> 来自此前讨论的核心目标：4 人局可接受，重点解决 **5～8 人** 时每人都感觉自己参与了博弈，而不是仅能按一个按钮。

## 1. 分清「允许参与」与「值得参与」

现有规则已经保证每名存活玩家本轮都有出牌权，但仍可能产生：
- 初始指向在 n 人中均匀随机，目标外玩家感觉自己没有即时危机。
- 手牌可跨轮保存，出牌有机会成本；目标外玩家可能倾向长期 PASS。
- 每个人都秘密同时决策，个人很难直观感知自己的某次出牌究竟改变了谁的命运。
- 因所有人的行动会相互抵消，个人贡献常被最终结果掩盖。

这些是**假设**，不是测试结论；先让真实玩家试玩确认是否存在、严重到什么程度。

## 2. 第一轮测试：不改规则

最小规模：5、6、7、8 人；可用真人优先，人数不足的测试不能冒充完整真人体验。

建议记录每轮：
- `alive_count`、`initial_target_id`、每位玩家手牌数量及牌面；
- 每位玩家是否 PASS、是否位于初始目标、打牌方向及数值；
- `result_target_id`、累计牌数、对局时间；
- 每名玩家主观评分（「这一轮我有决策空间吗」「我知道自己为何出牌吗」）。

建议的观察指标（不是硬性产品阈值）：
- 总 PASS 比率及非初始目标玩家的 PASS 比率；
- 全员 PASS 回合比例；
- 每名玩家在淘汰前至少出牌一次的比例；
- 淘汰时剩余未用牌数；
- 「无有效参与」的主观反馈出现频率。

特别比较 4 人、5～8 人之间的曲线，而不是只看总对局时长。

## 3. 零规则改动就能做的体验提升 [优先验证]

A. 进入 CHOOSING 前把「所有人手牌」「初始目标」「当前轮盘顺序」明确展示；不要隐藏信息来制造伪策略。

B. 玩家选牌时，在本地提供 **「仅按你自己的动作计算时的临时落点」** 预览；醒目标明其他人的秘密动作尚未计入，不能把它称为实际必然结果。要评估是否破坏心理博弈氛围。

C. 统一公开时逐个标亮每个人的选择，再显示合计位移与最终落点，让贡献可追溯。**仅改变演出，不改变服务端求和和淘汰规则。**

D. 统计面板除了牌数，也可显示本轮「已确认 X/Y」；不可展示谁出了什么牌。

## 4. 若仍缺少博弈，才讨论机制改动（候选、未通过）

| 候选 | 预期效果 | 代价与风险 |
| --- | --- | --- |
| 为非目标玩家提供额外的出牌收益或代价 | 激励主动参与 | 改变资源经济，可能降低囤牌策略 |
| 调整起始指向的产生方式 | 提升可预测性/仇恨关系 | 与「随机起点」已确认规则冲突，需重写规则及协议 |
| 在结算反馈中加入「个人影响」表现 | 增强参与感，规则影响小 | 同时出牌时无法公平归因，不宜硬算「是谁救了谁」 |
| 引入额外互动阶段 | 增加社交对抗 | 拉长局时，给联网状态机增加复杂度，不建议 GameJam 首版 |

建议先尝试 **界面反馈 + 真人测试**，再考虑增加玩法复杂度。任何调整都应有正反两组数据和单独需求变更。

## 5. 验收与决策输出

试玩记录模板：
- 局号、构建版本、玩家人数、网络环境、总轮数、平均回合时长；
- PASS 率、初始目标与非目标行动差别、玩家平均行动次数；
- 主观问卷及关键原话、观察到的卡顿或网络错误；
- 是否接受现有规则 / 需要 UI 调整 / 提议正式变更规则。

**当前没有真实数据，不能断言 5～8 人玩法已经改善。**
