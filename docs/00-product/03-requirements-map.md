## 其他交付边界

- **牌数统计**：已发/已出/淘汰弃/剩余，恒等式见 [规则](../01-gameplay/01-rules.md)，验收 A10。
- **现有人机原型**：原文声称存在，**实际新工程不存在**；参见 [范围勘误](01-brief-scope.md)。
- **在线人机补位（D-08 已确认）**：P1；首版不会各客户端自行运行机器人以影响权威结果。
- **已确认（D-04～D-07）**：房主创建与开始、全员准备、**每轮 15 秒**（提前全员确认可揭晓）、掉线保留席位并自动 PASS、终局回房重新准备及拒绝中途加入。见 [决策簿](02-open-decisions.md)。
- **P0 客户端和服务器交付**：见 [施工阶段](../05-engineering/03-roadmap.md) 和 [公网测试](../03-network/02-deployment.md)。

## 二次网页调研的追踪补充（状态：未实现）

本文件每个 NET/UI 编号的技术可行性、风险等级和实测前提已逐条记录在 [P0 可实现性审计](../05-engineering/04-feasibility-audit.md)。特别关注 NET-01（公网 UDP 可达）、NET-07（客户端确实收不到秘密动作）、NET-08（超时竞态）、NET-13（默认 peer relay 与跨房隔离）、UI-07（12 人窄扇区和最多 11 张个人累积牌）。原验收 A01～A11 均保留，**没有将网页 API 存在当作功能通过**。

## 2026-11-18 已确认内容与验收补充

- NET-04：至少 2 人且全部准备才允许房主开始；普通成员不能强制开局。
- NET-08：服务端启动 CHOOSING 即开始 **15 秒**计时；所有存活者确认（包括依断线规则自动 PASS 的玩家）可以提前公开；未确认者到期 PASS。
- NET-11：开局前退出移除；对局中断线动作/席位按 D-06 处理，不引入即时淘汰。
- NET-12：终局统一返回房间、所有成员准备重置，拒绝对局中途加入。
- 人机补位 P1；联机 **D-03 选型仍待讨论**，不影响上述行为级验收要求。

## 2026-11-18 P2P 需求映射更新（覆盖旧集中式设计落点）

- **NET-01** 原上传文件写统一服务地址；P2P 下需要独立确定如何发现房主、如何通过不同 NAT 连接。直接 IP/端口、WebRTC/信令、Steam Lobby 等方案由 D-03b/c/g 决定，不能默认固定服务器。
- **NET-02～04** 房主建房、凭码加入、>=2 且全员准备后房主开始已确认；**短房间码到网络会话的映射**仍需确定。
- **NET-05～10** 稳定身份、15 秒、秘密决定、统一揭晓与最终一致不能降低标准。若 Host 收明文动作，房主玩家可提前知道别人的牌与方向，D-03d 必须确认保密边界。
- **NET-11** 一般成员掉线保留席位/自动 PASS 已确认；**Host 掉线**的整局中断或迁移是独立 D-03f。
- **NET-12/13** 终局回房重置准备、房间消息隔离仍必须满足；P2P 的房间管理可能由 Host 或游戏平台 Lobby 实现。
- **A01/A11** 不同网络真正公网连接与非开发机运行仍是 P0；若需要平台/信令/TURN/中继，交付必须说明这些依赖。
- 本文件较早的固定服务器技术落点属于**已覆盖的旧方案**；以 [P2P 架构 RFC](../02-architecture/03-p2p-architecture-options.md)、[P2P 公网连接方案](../03-network/03-p2p-connectivity-options.md) 为准。

## LIFE-01 初始生命可调需求追踪（2026-11-18）

- 来源：用户最新要求“加入初始生命可调整”，原始初始血量未确定。当前 Demo 实现：**房主开局前设 1～5，默认 1，全体相同**；命中扣 1，归零才淘汰。
- 设计：[规则文档](../01-gameplay/03-initial-lives.md)、[领域模型](../02-architecture/02-domain-state.md)、[UI 规范](../04-ui/01-ui-ux.md)；实现：`game_rules.gd`、`game_session.gd`、`main.gd`、`wheel_view.gd`。
- 验收：大厅客户端显示同步设置；两人 3 生命命中后 HP 2→1→0，前两轮不淘汰/不弃牌，第三轮淘汰；设置为 1 时旧规则仍正确；规则牌数守恒。
- 以前 A02/A03/A06 等验收默认“每轮必淘汰”，现应以**生命归零才淘汰**为准，其他联机交付标准不变。
